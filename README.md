# 我的世界基岩版开服教程：从买服务器到改 server.properties，零基础也能搭出手机、电脑、主机都能进的 BDS 服

想开基岩版服务器的人，卡住的地方往往不是不会开服，而是不知道从哪一步开始。家里电脑双击一下 `bedrock_server.exe` 就能跑，可朋友连不上；换成租服务器，又冒出一堆 UDP、端口映射、`online-mode` 的选项。

这篇把流程拆成两条可执行路线：一条是五分钟搞定的云端一键部署，一条是自己能改配置的面板服。中间穿插基岩版最容易踩的坑，最后给一份能直接对比的配置价格表。

## 先明确一件事：基岩版开服和 Java 版不一样

很多网上抄来的教程是 Java 版的，套在基岩版上必然翻车。几个硬差异先记住：

- **官方服务端 BDS 是免费的**，从 Minecraft 官网下载，只有 Windows 和 Ubuntu 两个版本，Linux 侧官方只支持 Ubuntu 22.04 LTS 及更高版本，其它发行版不保证能跑。
- **基岩版走 UDP，默认端口 19132（IPv4）和 19133（IPv6）**；Java 版走 TCP，默认 25565。端口开放时如果只放 TCP，客户端表现就是一直"正在连接"。
- **基岩版和 Java 版完全不兼容**，插件、模组、服务端核心不能互换。基岩版能跨 iOS、安卓、Xbox、Switch、Windows 一起玩，这是它最大的优势，代价是没有 Java 那套插件生态。
- **服务端版本和客户端版本必须一致**。基岩版客户端会自动更新到最新版，所以服务端也建议跟着升，否则老玩家能进、新玩家进不去。

系统配置要求不高：官方给出的基准是 Intel Core i3 3210 或 AMD A8 7600 APU 级别处理器、4GB 内存、1GB 左右的硬盘空间。注意这是"能跑起来"的门槛，不是"开着舒服"的门槛。

## 本机开服还是租服务器：先算这笔账

在自己电脑上开服能省下服务器钱，但有几个绕不开的现实：

- 家用宽带大多没有公网 IPv4，需要内网穿透，延迟和稳定性看穿透服务脸色；
- 电脑不关机才能一直开服，关机电费是零，服务器也跟着没了；
- 多人长期玩，存档、备份、跨平台连接都变得麻烦。

## 基岩版 server.properties 里真正要动的几个参数

BDS 的配置项比 Java 版少，改完重启实例才生效。这几项是实际会影响联机体验的：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `server-name` | Dedicated Server | 服务器列表里显示的名字 |
| `gamemode` | survival | survival / creative / adventure |
| `difficulty` | easy | peaceful / easy / normal / hard |
| `allow-cheats` | false | 想用 `/tp`、`/gamerule` 这类指令必须改 true |
| `online-mode` | true | true 时只有正版 Xbox 账号能进；离线玩家必须改 false |
| `max-players` | 10 | 最大在线人数，受内存和单核性能限制 |
| `view-distance` | 32 | 视距，最吃性能的一项，配置一般建议压到 6–12 |
| `tick-distance` | 4 | 模拟距离，影响刷怪和红石范围，4–12 |
| `server-port` | 19132 | 必须和你在控制台做的端口映射一致 |
| `server-portv6` | 19133 | 没有 IPv6 可以不管 |
| `server-authoritative-movement` | client-auth | 改 server-auth 会提升移动同步精度，但更吃性能 |

两个新手最容易犯的错：

- 把 `server-port` 留在 19132，却没做端口映射，或者映射时选了 TCP。**基岩版必须走 UDP。**
- 在 Windows Server 2012 之类的老系统上跑 BDS。官方 Windows 侧要求 Windows 10 10.0.15063 以上或 Windows Server 2016 以上，低于这个版本根本起不来。

## 端口和端口映射：基岩版翻车最多的地方

基岩版服务器最终的连接地址是 **公网 IP + 外网端口**，两个都对才能进。云服务器通常没有独立公网 IP，需要做 NAT 端口映射。

雨云控制台的 **NAT 端口映射管理**里新建规则：

- **内网端口**：填 `19132`
- **协议**：选 `UDP`，或者 `TCP+UDP` 图省事
- **外网端口**：范围被限制在 **7000–60000**，且不能用 80、443、25565、19132 这类常用端口

所以别人看到的地址不会长得像 `1.2.3.4:19132`，而是类似 `1.2.3.4:27165`。映射规则一般 1–2 分钟生效。

如果你用的是云应用那条路线，端口已经在应用创建时分配好了，在"服务"页面能直接看到映射关系，不用自己配。

系统防火墙那边，Ubuntu 上放行端口就两行：

bash
sudo ufw allow 19132/udp
sudo ufw reload


Windows 上跑 BDS，第一次启动时系统会弹防火墙提示，要允许它通过公用网络，否则外网玩家进不来。

## 让玩家进来，以及给管理员权限

客户端操作：进入游戏 → **游戏 → 服务器 → 添加服务器**，服务器地址填公网 IP，端口填映射后的外网端口。

基岩版和 Java 版有个区别：**基岩版的 OP 不靠控制台打名字那么简单**，它认的是玩家的 XUID。在 MCSM 或云应用的终端里执行：


op 玩家名字


终端里输入的指令不需要加 `/`。常用指令还有 `list`（在线玩家）、`save-all`（强制存档）、`stop`（安全关服）、`kick`、`ban`、`tp`。日常维护建议清档前先 `save-all` 再 `stop`，直接断电式关服容易丢存档。

## 几个高频问题

**"无法连接至世界"** —— 九成是端口映射问题。检查协议是不是 UDP、外网端口和内网端口是否和 `server-port` 对得上。用 PocketMine-MP 这类端时，内网端口和外网端口必须完全一致，否则一定连不上。

**手机能进、电脑进不去（或反过来）** —— 版本不一致。基岩版对版本号卡得很死，服务端升上去或者降下来，让两边对齐。

**能进但卡** —— 先看视距和模拟距离，再把不必要的高频红石机器、大量实体清理掉。服务器 TPS 掉下来时，表现出来就是操作有延迟感，而不是画面卡。

**存档备份** —— 在 MCSM 的文件管理里定期把 `world` 文件夹下载下来，或者用面板的备份功能。别指望一直不出事。
